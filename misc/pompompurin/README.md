# Pompompurin

Author: Stella

I found this cute Pompompurin at an airport! What terminal is this store in and what zipcode is this store in? Surround your answer in the flag format `gigem{<terminal>_<zip_code>}`. For example, for terminal 1 and zip code 77844, the flag would be `gigem{1_77844}`.

## Solution

Take the provided image and do a google reverse image search to find this link: https://www.dfnionline.com/latest-news/ever-rich-duty-free-unveils-new-stores-taoyuan-airport-25-04-2023/

The site has a caption for that image: "Hello Kitty store at C2 Gate, Terminal 2". 

This matches the C2 as seen in the image provided. Also, in the article it mentioned that this is at Taoyuan Airport in Taiwan which matches the language seen in the provided image. When looking up that airport this is the full address: No. 9號, Hangzhan S Rd, Dayuan District, Taoyuan City, Taiwan 337

So the terminal is 2 and the zipcode is 337 making the flag gigem{2_337} as per the formated mentinoed in the description.

flag:
`gigem{2_337}`
