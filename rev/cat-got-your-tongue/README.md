## Solution

First loaded in the Project.sb3 file into Turbowarp and saw that it was a Scratch file that was a flag checking program.

When unzipping Project.sb3 there are a few svg files and a wav file that's used in the flag checking scrath program and a project.json file. When loading the json file into a viewer and searching for gigem the first part of the flag could be found. The flag was split into four parts in the json file and when put together it can be submitted back into the loaded Project.sb3 to check the flag is correct. 

It then shows "Wow that looks amazing!" which confirms the flag is correct.
