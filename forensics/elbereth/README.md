## Solution

First, gunzip the bonD0.5.gz file to get bonD0.5 bones file. By looking in the file it can be seen that it was made with wizard mode. By putting the bones file in the correct location where it is checked and using wizard mode to go to the correct level (5) there is a random chance (1/3) of getting the flag each time. Once the bones file loads after a few tries then the flag is displayed.
